# 🪵 3号機：丸太・LOGを投じる航行記録（Log Template Specification）

> *“丸太（LOG）を投じ、速度を測り、刻む――それは魂の航海記（WILL）の原点である。”*

当リポジトリ（`Templates/log-template`）は、沖縄の母艦（`ryubostyle`）から発進するすべてのプロジェクトが、時空の座標と航海の速度を刻むための「航行記録」を保持する零戦（3号機）の仕様書である。

---

## ⚓ 第一章：LOGからLogueへの昇華
海原に丸太を投じて物理的な重力と速度を測ってきた「LOG」の記憶は、空の領域における知性と霊性の共鳴「Logue（対話）」へと引き継がれる。
本テンプレートは、日々の試行や航海の節（KNOT）を正確に時空へ定着させるための構造を提供する。

## 📍 第二章：KNOT（節）の構造
* **KNOT 01（運玉森など）：** 未知への招待と霊的な起点。
* **KNOT 02（与那原の海など）：** 時空を超える跳躍と音律の共鳴。
各航行記録は、このテンプレートを基にしてディスプレイ上（Screen）に美しくホログラフィ化される。

## 🚀 第三章：発進シークエンス
フィルム（Film）としてのYAML仕様とMarkdownの結合が完了したとき、3機の零戦（`library-scroll`, `story-background`, `log-template`）の隊列が整い、母艦 `ryubostyle/Templates` から完全なる発進の時を迎える。
