# OPModel（OrientedPhilosophiaModel）の概念策定と設計指針

## 1. 概要・背景
これまでに構築してきた複数の静的サイト群（「飲茶坊さとし」のOrientedPhilosophia概念に基づくシステム）の設計思想を抽出し、より柔軟で再利用性の高いメタモデル**「OrientedPhilosophiaModel（OPModel）」**として構造化・再定義する。

---

## 2. OPModel のメタファーと構成要素（映写機モデル）

OPModelでは、各システム要素を映画の「上映システム」になぞらえて定義・カプセル化する。

| 象徴 | コンポーネント | 役割と内容 |
| :--- | :--- | :--- |
| **Film** | `Template` / `Design` / `Structure` | コンテンツ（Markdown）、デザイン（CSS）、スケルトン構造（HTML）。 |
| **Projector** | `build.py` | FilmおよびRelation定義を読み込み、結合・変換を行うコアエンジン。 |
| **Screen** | `index.html` / 配信サイト | 最終的に生成され、ユーザーに表示される静的成果物。 |

---

## 3. カプセル化（Beans）と関係性定義（Relation）

各リポジトリを **Bean**（独立した機能・機能群）として独立・カプセル化させ、リポジトリ間の継承および依存関係を `relation.yaml` で定義する。

### `relation.yaml` 標準フォーマット案
```yaml
# OrientedPhilosophia Relation Definition
name: My-Site-Instance
version: 1.0.0
model: OrientedPhilosophiaModel

# 継承元・依存リポジトリの定義 (Beans)
extends:
  structure: "[https://github.com/ryubostyle/Structure-Base.git](https://github.com/ryubostyle/Structure-Base.git)"
  design: "[https://github.com/ryubostyle/Design-Theme.git](https://github.com/ryubostyle/Design-Theme.git)"
  template: "[https://github.com/ryubostyle/Template.git](https://github.com/ryubostyle/Template.git)"

# 本リポジトリ固有のオーバーライド設定
components:
  content_dir: "./documents"
  assets_dir: "./assets"
  output_dir: "./dist"

# Projector（build.py）の設定
projector:
  engine: "build.py"
  entry_point: "index.html"
  cache_beans: true
