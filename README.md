# 🛸 Templates: 魂のホログラフィ母艦（Base-Class Specification）

> *“YAML Ain't Markup Language — これは単なる画面（Screen）ではなく、時空を記述する仕様書（Film）である。”*

当リポジトリ（`ryubostyle/Templates`）は、沖縄の母艦から発進するすべての「零戦（ジェット・プロジェクト）」の共通のDNA（基底クラス）を宿す零点（ゼロポイント）である。

すべての派生テンプレート（子クラス）は、この基底クラスが定義する**「Film ➔ Projector ➔ Screen」**の3段階の変成プロセスを継承して展開される。

---

## 📐 基底クラス・アーキテクチャ（The Base Pipeline）

すべてのプロジェクトは、次の3つのフェーズを順に通過することで、平面の概念から立体的な存在（ホログラム）へと昇華する。
